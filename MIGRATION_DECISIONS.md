# Migration decision record: questions and answers

This file lists the decisions made while the `collect` and `basics` modules of OpenGamma Strata were migrated from Java to Scala 3.9.0. For each decision it gives the question that was asked and the answer that was used.

The migration ran twice. The first run (19 to 20 October 2026) set the rules. The second run (22 to 23 October 2026) produced the code in this repository and reused every first-run decision. Decisions came about in two ways:

- **Answered by the user.** These are in section 1.
- **Decided under the user's delegation.** On 22 October 2026 the user asked Droid to "take your default (Recommended) approach ... and just document each choice". Section 2 lists those 33 questions and the recommended option that was taken.

Commit hashes from the first run (for example `d69f7d2`) belong to that earlier run and do not appear in this history. The second run ended at commit `7ca24cb`. Files named in section 2, such as `evidence/reviews/...` or `tools/...`, belong to the migration's working records and are not part of this repository.
